# Elemental attack sounds — provenance and credits

The ten clips in this folder are REAL recordings of real things — no
synthesis, no AI audio (Nigel's law: real over synthetic; the synthesized
set was struck 2026-10-26 as "computery and 8-bit sounding", and this
recorded set was approved the same morning: "add these sounds for he
elemental attacks").

Each element has a CAST clip (the attack loosed) and a HIT clip (the
attack landing). The clips were cut from the approved audition pairs in
`~/workspace/element-sound-real/` (cast = the pair's first segment, hit =
the segment beginning at 0.80 s), with short clean fades and the levels
exactly as approved (peaks ≈ 0.52, never re-normalized).

Freesound's full-resolution originals sit behind a member login, so the
audition pairs — and therefore these clips — were cut from Freesound's
own official HQ preview of each named recording: the same recording, in
the site's preview encode. The Wikimedia thunder file is the true
original. Every license below permits this use; the two CC BY credits
are also carried in the app (the About/lore section of the main page,
beside the music credits).
